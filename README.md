# Smart Bag Optimizer – Algorithm Explorer

A beginner-friendly web project that explores the **0/1 Knapsack Problem** using four algorithmic approaches:

1. Brute Force
2. Greedy (value-to-weight ratio heuristic; not always optimal)
3. Dynamic Programming
4. Backtracking

## Project structure

```text
Smart-Bag-Optimizer/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
```

## Run locally

1. Extract the ZIP file.
2. Open the `Smart-Bag-Optimizer` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit the three main files as you develop the project.

## Current starter status

The responsive dark dashboard, sample items, item form, basic validation, algorithm tabs, and comparison-table layout are included. The algorithm functions and result calculations are intentionally left for the next implementation steps.

## Deployment

Push this folder to a public GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.
